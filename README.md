# HWP/HWPX 뷰어 PWA

정적 파일만으로 동작하는 브라우저/PWA 배포본입니다. 사용자가 선택한 문서는
브라우저의 `File.arrayBuffer()`로 읽고 기기 안에서 처리하며 서버로 전송하지
않습니다.

## 로컬 실행

서비스 워커는 `file://`에서 정상적으로 동작하지 않으므로 HTTP로 실행합니다.

```powershell
cd pwa
python -m http.server 8081
```

브라우저에서 Python 서버가 표시한 로컬 주소를 엽니다.

## 정적 호스팅

모든 애플리케이션 경로는 상대 경로입니다. 저장소 하위 경로에 `pwa/`의 내용을
배포할 수 있으며 별도 백엔드나 Node 런타임은 필요하지 않습니다. 첫 방문에는
애플리케이션 파일을 내려받기 위한 네트워크 연결이 필요합니다. 서비스 워커 설치와
자산 캐시가 완료된 뒤에는 로컬 HWP/HWPX 파일을 오프라인으로 열 수 있습니다.
