# 쿄쿄뷰어 PWA

정적 파일만으로 동작하는 HWP·HWPX 문서 뷰어입니다. 선택한 문서는 브라우저 안에서 `File.arrayBuffer()`로 읽고 `@rhwp/core` WASM으로 렌더링합니다. 문서 데이터는 서버로 업로드되지 않습니다.

최근 문서는 편의를 위해 IndexedDB의 `kyokyo-viewer` 데이터베이스에 최대 10개까지 저장됩니다. 이 저장소는 백업이 아니며, iOS/Safari가 기기 저장 공간 상황에 따라 데이터를 정리할 수 있습니다. 원본 Files 문서는 삭제하거나 변경하지 않습니다.

## 로컬 실행

서비스 워커는 `file://`에서 정상적으로 동작하지 않으므로 HTTP로 실행합니다.

```powershell
cd pwa
python -m http.server 8081
```

브라우저에서 `http://localhost:8081/`을 엽니다.

## 정적 호스팅

모든 애플리케이션 경로는 상대 경로입니다. 저장소 하위 경로에 `pwa/` 내용을 배포할 수 있으며 별도 백엔드나 Node 서버가 필요하지 않습니다. 첫 방문에는 애플리케이션 파일을 캐시하기 위한 네트워크 연결이 필요합니다. 서비스 워커 캐시가 완료된 뒤에는 앱 실행과 로컬 HWP·HWPX 열기가 오프라인으로 동작합니다.

사용자 문서는 Cache Storage에 넣지 않으며, 최근 문서 데이터만 IndexedDB에 보관합니다.
